# 豆豆乐园

给 3–5 岁小朋友的网页小游戏。打开就能玩，不用登录，也不用联网。

小狐狸豆豆会陪着小朋友做四件事：

- **吹泡泡**：点破彩色泡泡，听到颜色的名字
- **找动物**：看着图片，找出小猫、小狗、小鸭
- **数一数**：从 1 数到 5，可以一个一个点着数
- **涂颜色**：给小花园涂色，也可以按「变变变」换成晚霞和夜晚

没有倒计时，也没有失败。点错了会再试一次，数数时豆豆会带着一起数。星星只是收集，存在这台设备的浏览器里。

## 怎么打开

用电脑、平板或手机的浏览器打开 `index.html`。

声音按钮可以随时关掉音效和朗读。建议和爸爸妈妈一起玩，平板横过来、竖过来都可以。
